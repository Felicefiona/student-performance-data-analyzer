# Student Performance Data Analyzer

A beginner-friendly Python project that analyzes student marks using CSV file handling.

## Features

- Reads student marks from a CSV file.
- Calculates each student's average marks.
- Calculates the overall class average.
- Identifies the top-performing student.

## Technologies Used

- Python
- CSV file handling
- Git and GitHub

## Project Files

- `main.py` — contains the Python program.
- `students.csv` — contains sample student marks.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   `python main.py`

## Learning Outcomes

This project demonstrates Python loops, lists, dictionaries, file handling, functions such as `sum()` and `max()`, and basic data analysis.
